# Supernatural

Site sobre a série Supernatural.

## Sobre o projeto

Este site foi criado como um trabalho escolar utilizando HTML, CSS e JavaScript.

O site apresenta informações sobre a série, seus personagens, criaturas, temporadas, o Impala 1967 e alguns objetos importantes da história.

## Conteúdos

- Sobre a série
- Personagens
- Criaturas
- Temporadas
- Impala 1967
- Armas e objetos
- Vídeo
- Interações com JavaScript

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
